# Chromium 扩展：南大 LMS 文件下载

在 Chrome、Edge 等 Chromium 浏览器中打开 LMS 学习活动，点击扩展图标，选择附件即可交给浏览器下载管理器保存文件。无需 Python，不导出 Cookie。

## 从源码安装

1. 获取本仓库源码。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择 `chromium-extension` 文件夹，即包含 `manifest.json` 的目录。
5. 固定扩展到工具栏，刷新已打开的 LMS 页面。

不需要 `npm install` 或构建步骤，全部脚本随源码提供，不加载远程 JavaScript。

## 使用

1. 在同一浏览器中正常登录 `https://lms.nju.edu.cn`。
2. 打开具体活动，例如 `https://lms.nju.edu.cn/course/11611/learning-activity#/44877`。
3. 点击工具栏中的「南大 LMS 文件下载」，再点击附件旁的「下载文件」。
4. 在浏览器下载列表确认完成状态。文件默认位于下载目录的 `NJU-LMS/活动编号/` 下，实际保存行为也可能受浏览器设置和策略影响。

默认保留重复文件，由浏览器增加编号。切换活动后重新打开扩展或点击「重新读取」。页面已切换但列表未更新时，扩展会拒绝旧活动的下载请求。登录过期时请正常登录，再刷新页面。

弹窗的「已交给浏览器」仅表示已启动下载，关闭弹窗后下载可以继续，完成或中断状态以浏览器下载列表为准。

## CRX 打包与签名

开发者可使用浏览器内置「打包扩展程序」生成 CRX3：

1. 在扩展管理页开启开发者模式，选择「打包扩展程序」。
2. 扩展根目录选择本目录。
3. 首次打包由浏览器生成私钥，或选择已有的开发者签名私钥。后续版本沿用同一私钥，以保持 CRX 扩展 ID。
4. 妥善保管生成的 `.pem`，不要放进扩展根目录、安装包、公开仓库或 Issue。当前本地维护密钥保存在仓库的 `.auth/signing/extension.pem`，该文件不会随克隆分发。
5. 更新扩展前递增 `manifest.json` 的版本号，再以同一密钥打包。

源码加载时的开发者扩展 ID 不保证与签名 CRX ID 相同。私钥丢失可能导致不能以相同身份继续签名更新；泄露则会损害该身份的可信性。

开发者签名用于包完整性校验和身份识别，不等于商店审核或官方认证，也不会取消安装限制。Windows/macOS Chrome 对商店外 CRX 安装有限制，个人开发建议加载源码；普通分发应使用商店等受支持渠道，不要关闭防护或擅自修改组织策略。参考 [Chrome 官方分发说明](https://developer.chrome.com/docs/extensions/how-to/distribute?hl=en)。

本仓库只提交源码，不提交私钥、打包 CRX 或课程文件；不保证提供已发布的商店版本。

## 工作方式与源码

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | Manifest V3 声明、权限和入口 |
| `content.js` | 在 LMS 页面同源读取活动和文档阅读地址，核对活动及附件 |
| `background.js` | 检查扩展消息来源，将文件地址交给浏览器下载 API，清理文件名 |
| `popup.html` / `popup.js` / `popup.css` | 展示附件列表及下载入口 |

内容脚本请求 LMS 同源接口，浏览器自动附带当前会话 Cookie。后台通过 `chrome.downloads.download` 请求服务器返回的 HTTPS 文件地址；不手动将本站 Cookie 转发给文件服务器。

扩展可解析数字课程编号的活动 URL，目前只对课程 11611 的文档接口做过实测。仅支持 `document` 附件，不包含视频下载、课程批量抓取、预览截图导出或自动重新登录。使用文档阅读接口不代表取得版权或下载授权，接口拒绝访问时停止该附件获取。

扩展不在下载前完整读取文件，不核对附件长度、不计算 SHA-256、不生成 HTTP 报告，也不执行恶意软件扫描；需要现有文件校验能力时，可使用仓库的 Python 下载器。

## 权限和隐私

- `activeTab`：用户点击扩展时读取当前标签页信息。
- `downloads`：启动所选附件的浏览器下载。
- `https://lms.nju.edu.cn/*`：在 LMS 活动页运行内容脚本；实际匹配范围见 manifest。

不申请 Cookie API 权限，不导出或持久化 Cookie，不设置第三方分析上报。打开弹窗会读取活动信息，点击下载才请求文档地址并启动下载。临时地址不写入扩展存储，但浏览器下载历史、学校平台及文件服务仍可能保留正常记录。

## 故障排查与已验证范围

- 提示无法连接页面：安装或更新后刷新 LMS 标签页，再打开扩展。
- 提示需要活动编号：进入具体活动，地址应包含 `#/编号`。
- 提示页面已切换：点击「重新读取」。
- 提示接口失败或下载中断：检查登录、网络、平台权限及浏览器下载列表，确认授权后再重试。
- CRX 无法安装：不意味着签名必然错误，也可能是浏览器安装策略限制，使用源码开发者加载方式验证。
